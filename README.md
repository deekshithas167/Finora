# Finora — Field Desk

Finora — Field Desk is a financial planning and cash-flow management prototype designed to help users understand their income, track expenses, prioritize upcoming payments, and make better financial decisions.

## Features

- 📊 **Financial Dashboard**
  - Overview of income, expenses, available balance, and financial activity.
  - Visual representation of financial trends.

- 💰 **Income Tracking**
  - Track income sources and incoming cash flow.
  - Upload income documents to help calculate and track income.

- 📈 **Financial Analytics**
  - Interactive graphs for understanding income and expense patterns.
  - Different viewing modes for analyzing financial activity.

- 💳 **Payment Management**
  - View upcoming and recurring payments.
  - Payments are organized according to priority.
  - Urgency indicators help identify payments that require attention first.

- 🔔 **Reminders**
  - Dashboard reminders for upcoming financial obligations.
  - Helps users stay aware of important payments and deadlines.

- 📄 **Document-Based Financial Analysis**
  - Supports uploaded financial documents.
  - Demonstration documents are included in the repository.

- 🔐 **Secure Login**
  - Login protection for accessing the financial dashboard.

- 🎨 **Modern Interface**
  - Clean, responsive dashboard designed for quick financial decision-making.
